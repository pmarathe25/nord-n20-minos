Privacy policy

Minecraft Phone Backup is a personal project intended to transfer its owner's Minecraft world backups from a phone server to the owner's Google Drive.

With the owner's permission, the backup software will use the Google Drive API to create and manage backup files. The world data is stored in the owner's Drive account. Google handles that data under its own privacy policy. GitHub hosts these informational pages and may record visit information under its privacy policy.

The project is not a public service and is not intended to share or sell Google user data. Authorization credentials are stored on the owner's devices. The owner can revoke the app's Google Account access through Google Account security settings and can delete backup files from Drive.

Backups are being developed and are not yet configured. This policy will be updated if the app's data practices change.
